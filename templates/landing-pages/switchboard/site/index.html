THE PRACTICAL DETAILS

Clear by design.

A few honest answers about how this concept works.

What can I actually do here?

Add and edit work, assign owners, change status and priority, switch between board and list, search, check release gates, and export a Markdown handoff.

Where is the plan saved?

In this browser’s local storage. There is no remote account or team sync. If storage is unavailable, the current page still works and reports that changes are page-only.

Does marking a release ready deploy anything?

No. The release room is a planning checklist. Its export is a document, not a deployment or a message to teammates.

Can I restore the original example?

Yes. The workspace has a reset action with an explicit confirmation dialog. Export your current plan first if you want to keep it.
